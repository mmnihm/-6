# 会员网盘机器人

独立的 Telegram 会员文件网盘机器人。项目采用 Python + Pyrogram + SQLite，使用会员群验证权限，并将文件分别保存到两个私有 Telegram 频道（主存储与备份存储）。

## 当前版本

这是项目初始化版本，先完成基础运行链路：首次管理员认领、会员群验证、双频道存储、私有分享链接、文件取回、基础统计。后续再逐步增加批量分享、分类管理、会员手动授权/到期、广播与恢复管理。

**不包含支付、广告解锁、短链付费或任何收费接口。**

## 部署前准备

1. 创建 Telegram Bot，取得 Bot Token。
2. 创建一个会员群，并把机器人加入群内，确保机器人可以查询成员状态。
3. 创建两个私有频道（主存储频道、备份频道），把机器人设为管理员并允许发消息。
4. 将机器人部署到自己的 VPS，配置下方环境变量。

## 环境变量

复制 `.env.example` 为 `.env` 并填写：

- `BOT_TOKEN`：机器人 Token
- `API_ID`、`API_HASH`：Telegram API 凭据
- `MEMBER_GROUP_ID`：会员群 ID
- `STORAGE_CHANNEL_ID`：主存储频道 ID
- `BACKUP_CHANNEL_ID`：备份存储频道 ID
- `BOT_USERNAME`：机器人用户名，不带 @
- `DATABASE_PATH`：SQLite 文件路径（默认 data/bot.db）

## 启动

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## 首位管理员认领安全提示

按已确认的规则，部署后第一个在**私聊**中发送 `/start` 的 Telegram 用户会成为唯一超级管理员。请先启动机器人并立即由你本人私聊它完成认领，再公开机器人用户名。若提前公开，其他人可能抢先认领。管理员 ID 写入 SQLite，重启不会重新开放认领。

## 文件与权限说明

- 只有会员群成员及管理员可以上传、获取文件。
- 机器人需同时具备读取会员群成员状态、向两个私有频道发送消息的权限。
- 上传成功必须同时写入主频道和备份频道；若任一频道失败，不会把该文件登记为可分享文件。
- 分享链接使用 Telegram 深链，取回时优先主频道，失败时尝试备份频道。
- SQLite 使用 WAL 模式；数据库和频道消息都应纳入 VPS 备份计划。
